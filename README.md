# claude-mods

Mods for Claude's own interface: themes, panels, commands and more. Each mod lives in its own folder with its own README.

| Mod | What it does |
| --- | --- |
| [vaporwave](./vaporwave) | Neon pink, violet and cyan colors with an animated sunset, striped sun and a retro grid that scrolls toward you. |
| [guided-view](./guided-view) | A side panel beside the chat with the goal, Claude's plan and the step it is on, updated live. |

## Install a mod

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `nicolas-palermo/claude-mods`, then **Add plugin** and pick the mod.

At the prompt of a terminal session:

```
/plugin install <mod> --marketplace nicolas-palermo/claude-mods
```

From a shell:

```
claude plugin install <mod> --marketplace nicolas-palermo/claude-mods
```
