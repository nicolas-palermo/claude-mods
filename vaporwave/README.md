# Vaporwave

A vaporwave look for the Claude desktop and mobile apps: neon pink, violet and cyan colors, and an animated backdrop with a sunset sky, a striped sun, wireframe mountains, a palm tree and a retro grid that slowly scrolls toward you. Dark mode is neon on deep violet; light mode is a pastel sunset. Themes change colors and the backdrop only, so the app's fonts stay the same. The terminal draws no theme.

## Install

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `nicolas-palermo/claude-mods`, then **Add plugin** and pick `vaporwave`.

At the prompt of a terminal session:

```
/plugin install vaporwave --marketplace nicolas-palermo/claude-mods
```

Answer `y` to add the marketplace, then pick the user scope.

From a shell:

```
claude plugin install vaporwave --marketplace nicolas-palermo/claude-mods
```
